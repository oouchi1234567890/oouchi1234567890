## 自己紹介

業務システムの運用・保守を中心に、問い合わせ対応、障害の調査・対応、
ドキュメント整備、外部ベンダーとの調整、システム更改支援に携わってきました。
Java による開発・単体テストの経験もあります。

運用の現場で「何が困るか」を知っていることが強みです。
ディスク使用量の増え方から約半年後の容量不足を予測して対策を提案した経験や、
毎日の繰り返し作業をツールにした経験を、下の制作物としてまとめています。
